# GraPDF-Web

Web app for [GraPDF](https://github.com/jayrdeaton/GraPDF): merge every PDF linked from a webpage into a single downloadable booklet.

Live at [grapdf.infinitetoken.com](https://grapdf.infinitetoken.com). Built with Nuxt, Vue, and Tailwind CSS on top of the [`grapdf`](https://www.npmjs.com/package/grapdf) package.

## Getting started

```bash
npm install
npm run dev
```
